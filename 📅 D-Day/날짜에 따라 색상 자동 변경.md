## 🎨 날짜에 따라 색상 자동 변경하기 


### 색상 style
><img width="482" height="224" alt="스크린샷 2026-07-27 오후 12 10 22" src="https://github.com/user-attachments/assets/e343cdf1-bda4-48f7-a198-1f9e79b433b0" />

```javascript
lets(
  d,
  dateBetween(prop("마감일"), today(), "days"),
  
  ifs(
  
    d == 0,
    "D-DAY".style("b","green"),
    
    d < 0,
    ("D+" + format(abs(d))).style("gray"),
    
    d <= 3,
    ("D-" + format(d)).style("b","red"),
    
    true,
    ("D-" + format(d)).style("blue")
  
  )
)
```
