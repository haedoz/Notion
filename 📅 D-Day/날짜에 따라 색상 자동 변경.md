## 🎨 날짜에 따라 색상 자동 변경하기 


### 색상 style
><img width="488" height="272" alt="스크린샷 2026-07-27 오전 11 37 22" src="https://github.com/user-attachments/assets/61e1a3f4-ac3a-428e-8fe9-3841dfdfc15c" />

```
lets(
  d, dateBetween(prop("마감일"), today(), "days"),
  
  if(
    d == 0,
    style("D-Day","b","green"),
    
    if(
      d <= 3 and d > 0,
      style("D-" + format(d),"b","red"),
      
      if(
        d <= 7 and d > 3,
        style("D-" + format(d),"b","orange"),
        
        if(
          d > 7,
          style("D-" + format(d),"b","blue"),
          
          style("D+" + format(abs(d)),"gray")
        )
      )
    )
  )
)
```
